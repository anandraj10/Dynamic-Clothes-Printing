# 🧥 Dynamic Clothes Printing

A web-based application built with **React + Vite + TailwindCSS** for customizing clothing with dynamic prints.


## 🔧 Tech Stack

- [React](https://reactjs.org/)
- [Vite](https://vitejs.dev/)
- [Tailwind CSS](https://tailwindcss.com/)

## 📦 Installation

### Prerequisites

- Node.js (v16 or above)
- npm

### Steps

```bash
git clone https://github.com/anandraj10/Dynamic-Clothes-Printing.git

cd frontend

install npm

npm run dev
